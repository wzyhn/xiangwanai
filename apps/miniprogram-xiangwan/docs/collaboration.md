# 享玩小程序协作入口

在享玩独立仓库 Fork 后创建功能分支，提交 PR。维护者通过检查并接受后，产品代码的变化可以生成私有平台集成 PR；无需访问平台的其他 App。

## 开发与验证

在仓库根目录用 Node.js 24、pnpm 10.8.0 执行 `pnpm install --frozen-lockfile` 和 `pnpm test`。微信开发者工具导入 `apps/miniprogram-xiangwan`，执行“构建 npm”。公共工作区组件由安装后的同步脚本复制，不能直接修改生成的 `miniprogram_npm`。

运行配置在 `config/release.json` 与 `release.js`，两者必须保持一致。自己的测试 AppID、服务器域名和微信权限应匹配；服务端密钥只在服务器设置。真实账号、客户资料、数据库内容、支付证书及环境文件不能放入 PR。

## 贡献范围

小程序页面、业务 API、后台和享玩专属迁移接受项目级贡献。共享组件、根依赖及发行工作流需要额外的发行评审，不会自动回写平台共享实现。原有迁移只能新增前滚修复。

公开 PR 的合并、私有集成 PR 的合并、镜像构建和生产部署分别产生证据。两边同时编辑同一产品文件时保留冲突；重复同步同一提交复用原提案。
